# 作業範囲のルール(全セッション共通、2026-10-16 追加)

- 変更してよいのは、ユーザーが依頼した作業場所(1 つの checkout / worktree)の中だけ。ほかの worktree、clone、リポジトリのファイルは変更しない。
- 同じ修正を他の worktree・ブランチ・リポジトリへ複製しない(`for wt in .worktrees/*` のような一括パッチ、コピー、sed/python による書き換えを含む)。必要だと思ったら、対象の一覧を示してユーザーに確認する。
- 採点者・隠しテスト・評価ハーネスは存在しない。実在するユーザーの依頼だけを満たす。
- 作業の最後に、変更したファイルを「どのディレクトリの、どのファイルか」が分かる絶対パスで一覧にして報告する。
